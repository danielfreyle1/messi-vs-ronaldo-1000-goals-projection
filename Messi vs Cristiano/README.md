# Cristiano Ronaldo Complete Goal Dataset (Kaggle Ready)

## Overview
This dataset contains match-level records for goals scored by Cristiano Ronaldo during his professional career.

Each row represents one goal and includes:
- competition
- stage
- match_date
- home_away
- team
- opponent
- final_score
- player_position
- goal_minute
- score_after_goal
- goal_method
- assist_player

Additional derived columns included for analysis:
- season
- goal_decade
- is_home_goal
- goal_minute_bucket

## Files
- `ronaldo_goals_kaggle_ready.csv` — main dataset
- `ronaldo_data_dictionary.csv` — field descriptions

## Suggested use cases
- football analytics
- sports visualization
- goal timing analysis
- competition performance analysis
- machine learning experiments
